# Hoja de ruta comunitaria

Propuesta, no compromiso de fechas. Primero utilidad y seguridad; después más funciones.

## Estado de la versión preliminar

- [x] Demo local sin cuentas ni llamadas de red.
- [x] Dos ejemplos manuales n8n inactivos, con datos ficticios.
- [x] Documentación, pruebas automatizadas, licencias separadas y fondo CSS original.
- [ ] Validación visual en navegadores de escritorio y móvil, con teclado.
- [ ] Importación y ejecución en n8n de prueba; registrar versiones compatibles.
- [ ] Definir y verificar canal privado para reportes sensibles.
- [ ] Revisión del paquete integrado antes de cada actualización pública.
- [x] Taller local: notas a tareas editables y exportación.
- [x] Mapa 3D de ejemplo sin conexiones externas.

## Primeras mejoras para la comunidad

- Mejorar instrucciones con aportes de quienes lo instalen por primera vez.
- Plantillas de casos de uso pequeños: notas, documentos y seguimiento de tareas ficticias.
- Cargar el catálogo de agentes desde configuración, sin editar HTML.
- Accesibilidad, traducción y capturas verificadas del escritorio.

## Más adelante, solo con diseño y pruebas

- Conector servidor–n8n autenticado y autorizado, separado de la demo.
- Idempotencia persistente y cancelación entre ejecuciones; no confundir con la deduplicación actual del lote.
- Auditoría real y presupuestos del servidor, distinguidos de los ejemplos visuales.
- Voz opcional y mascota original, con consentimiento y revisión de licencias/modelos.

No hay integración automática con Dots ni agentes listos para operar en esta versión. Las sugerencias se conversarán antes de ampliar permisos o gastos.
